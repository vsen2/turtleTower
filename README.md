collect turtles to make them work in the store to make turtle money and buy more turtles and make more turtles work in the store!
I made it because I like turtles and laptops
still a work in progress
to run/play what is ready so far download the .exe file from itch.io https://victortheturtle.itch.io/turtletower 
HOW TO PLAY:
press start
buy some turtles
scroll down to go to the store
unlock a cash register with some coins
click the turtle menu in the top right corner
click a turtle to put him to work at the cash register 
make some more turtle coins to buy more turtles and get more cash registers!
thats it for now more updates coming soon!
